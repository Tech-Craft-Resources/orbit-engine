## Cálculo del NPS

```
Promotores (9–10): U1 (9) + U3 (9) = 2 usuarios → 2/3 = 66.7 %
Pasivos    (7–8):  U2 (8) = 1 usuario           → 1/3 = 33.3 %
Detractores (0–6): ninguno                       → 0/3 = 0.0 %

NPS = % Promotores − % Detractores = 66.7 % − 0.0 % = +67
```
