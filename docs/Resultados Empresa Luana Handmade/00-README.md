## Contexto de incorporación al piloto

Luana Handmade se unió al estudio de validación entre el cierre de las pruebas técnicas del Capítulo 5 y el inicio de la Fase 5. Su participación amplía el piloto a tres empresas con perfiles muy distintos: un negocio alimentario con equipo de 3 usuarios (Frozt Bitez), una tienda de moda con equipo mixto (Miss Peggy), y un emprendimiento artesanal unipersonal con una sola usuaria de mayor edad (Luana Handmade). Esta diversidad fortalece la validez externa de las conclusiones.
